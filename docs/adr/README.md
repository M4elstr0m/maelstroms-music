# Architecture decision records

Each record states what was decided, why, what was tried and rejected, and the evidence. Read the relevant record before changing the area it covers, and add a new record (or mark one superseded) when a decision changes. Records are numbered in the order they were written, a superseded record stays in place with its status updated.
